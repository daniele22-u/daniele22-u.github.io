Narcolepsy event monitoringMonitoraggio degli eventi di narcolessia

A desktop application to monitor and predict narcolepsy events, with the data workflows behind it.Un’applicazione desktop per monitorare e predire gli eventi di narcolessia, con i flussi di dati che la sostengono.

Python · SQL · XML

withcon Gabriele Carta · Filippo Saccomano

// What we builtCosa abbiamo realizzato

  • A Python application with a graphical interface to record, monitor and predict narcolepsy events.
  • Structured data workflows, with XML for data exchange and an SQL database for storage, plus visualisations of the recorded events.
  • A competitive analysis of existing devices and clinical data-management solutions.
  • Un’applicazione Python con interfaccia grafica per registrare, monitorare e predire gli eventi di narcolessia.
  • Flussi di dati strutturati, con XML per lo scambio e un database SQL per l’archiviazione, più visualizzazioni degli eventi registrati.
  • Un’analisi competitiva dei dispositivi e delle soluzioni di gestione dei dati clinici esistenti.
